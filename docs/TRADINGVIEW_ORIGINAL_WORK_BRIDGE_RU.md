## Как читать пакет обычному чату

Прочитать `tradingview-original-observations.json` по явному ref/commit исследовательской ветки, используя GitHub fetch_file или raw URL. Сверить observedAtUTC, barOpenUTC, barCloseUTC, nextExpectedBarCloseUTC и текущий UTC. После следующего ожидаемого закрытия хранить прежнее наблюдение только как историческое; не называть его последней свечой или live.

До merge файл отсутствует в main. Даже после merge штатный генератор не начнёт читать его автоматически: потребуется отдельное подключение consumer и тест команды в обычном чате. Для чтения уже опубликованного статического файла повторный запуск Work не нужен; для обновления оригинальных показаний сейчас нужен новый сбор Work.

Оригинальные значения использовать только внутри существующего технического конвергенционного слоя. Не заменять systemPrice значением Close из TradingView, не переписывать NAV/Spot/Futures/резерв/лимиты и не создавать торговый допуск. BIG GUY и его Burj mode дедуплицировать как один скрипт-источник.

## Разделение с независимыми расчётами

Проверены `indicators-technical-table.json`, `nadaraya-watson-research.json`, `market-summary.json`, `market-structure.json`, `docs/PIFAGOR_SIGNAL_BRIDGE_RU.md`, `docs/NADARAYA_WATSON_NON_REPAINT_RU.md` и генератор технической таблицы.

Существующая модель NWE_CAUSAL_GAUSSIAN_8_50_40_3_RESEARCH_PROXY_V1 остаётся MODEL_OBSERVED_UNVERIFIED_PARITY, notOriginalLuxAlgo=true. Её окна 50/40 отличаются от оригинала. Значения не скопированы в оригинальные наблюдения; статус PARITY_VERIFIED не присваивался.

У модели 1D закрывается в 16:00 UTC (биржевые сутки OKX UTC+8), у просмотренного TradingView 1D — UTC00. У ETH на 4H с закрытием 22.10 16:00 TradingView показывает минимум 2385,96, а market-structure.json — 2384,00 при совпадении O/H/C. Это отдельное расхождение входных данных, не доказательство перерисовки и не основание исправлять один источник другим.
