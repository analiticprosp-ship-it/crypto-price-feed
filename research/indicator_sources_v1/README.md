# Автосбор «Индикаторы»

Изолированный сбор публичных исследовательских данных, без торговых полномочий. Источник команды — latest.json и отдельные tv_runs; архив каждого серверного запуска — runs/<run_id>/receipt.json. Не считать старую technical-table полной картиной новых подключений.

Workflow Sequential Indicator Sources v1 запрашивает источники последовательно каждые четыре часа на 12-й минуте UTC. Возможна задержка расписания. Успех источника — COLLECTED_VALIDATED после проверки структуры/дат/покрытия; HTTP200 и успешный workflow сами по себе этого не доказывают. ACCESS_BLOCKED, FAILED, NOT_CONNECTED различаются. Последнее хорошее наблюдение при ошибке сохраняется как HISTORICAL_RETAINED_NOT_CURRENT.

OKX SPOT CVD — сумма buy-sell за 24 завершённых часа, база/площадка/границы окна сохранены. Coinbase — отдельные USD spot сделки с инверсией maker-side; полное покрытие окна обязательно, действуют лимиты времени/страниц и backoff429. Незавершённая выборка не даёт CVD. Дилерский знак гаммы не извлекается из OI. Deribit7d/30d IV и put-minus-call25delta — модель Black76 по markIV, отдельная от готовой метрики провайдера, с фильтром OI/двусторонних котировок и без экстраполяции.

FRED использует последние пересмотренные значения; не PIT. Индексы CPI/PCE не равны процентам инфляции, частота сохранена. Пять недельных релизов не являются пятью рабочими днями. Межрыночные сравнения — пять завершённых сессий; RSP/IWM только прокси ширины. BRK — адресные/возрастные когорты, LTH150d, независимые от entity-adjusted провайдеров. Дневные ряды исключают текущий незавершённый день. RWA distributed/represented/stablecoins не суммируются; 7d/30d не заменяют отсутствующее сравнение5BD.

TradingView читает отдельная задача «Сбор индикаторов и TradingView», каждые4часа. Создана и проверена частично: BIG GUY/LuxAlgo получены фоновым запуском, MFI и полный комплект4пар требуют успешного полного receipt. Используются согласованные избранные версии; параметры не менять. Пустая раскладка требует загрузки избранного, лимит2индикаторов — последовательного чтения и Undo с восстановлением исходной раскладки.

Точная ручная сверка всех4закрытых точек BIG GUY: tv_runs/20261031T114807Z.json; зелёные значения совпали. Не доказывает любую неперерисовку и не задаёт TP/SL. Фоновые попытки сохраняют собственные результаты отдельно.

Блокеры на вводе31.10: ISM требует human verification, CryptoQuant Apparent Demand403, Coinbase429/полнота истории ещё проверяются, entity-adjusted provider flows и настоящая ширина акций не настроены. Ожидаемые статусы не скрываются. Датированные старые пакеты можно показывать исторически, не выдавая за новый сбор.

Проверка кода: python3 -m unittest discover -s tests -p test_indicator_sources_v1.py -v. Защиты: незакрытые свечи/часы, разрывы/дубли, ошибки провайдера, нечисловые значения, инверсия Coinbase, нулевой skew плоской поверхности, запрет экстраполяции.
