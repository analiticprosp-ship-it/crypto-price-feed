# 09L-AUTO v1.0 — исследовательский автоконтур
Дата: 2026-10-22. **SHADOW ONLY**, не менять 00/01/01A/02/03/04/05/06/06C, Spot, Futures, NAV, резерв, P&L, капитал и лимиты.

## Что реально запущено
- `collector.py --mode daily` проверяет сохранённую историческую сверку 09L v0.8.6, при отсутствии локального файла автоматически получает общедоступные Tardis наблюдения ликвидаций BTC за последнее опубликованное первое число месяца: `bybit/BTCUSDT`, `okex-swap/BTC-USDT-SWAP`; SHA-256, числа строк, UTC, качество. **Это не непрерывная история тик-данных и не карта кластеров.**
- `--mode selftest` только локальные QA инварианты и дата публикации, без доступа к сети и ордеров.
- `--mode monthly` архивация одного месяца (уже сохранённый месяц не перезаписывается).
- `--mode pit` опционально получает CoinGlass **aggregate** Model2 BTC/3d только при наличии `CG_API_KEY` тарифа Professional/Enterprise и приватного S3-хранилища. В противном случае `PIT_SNAPSHOT_MISSING`. Не использовать произвольные старые карты как настоящие PIT. Фактические исходные данные никогда не публикуются в открытом GitHub; SHA и метаданные — в `derived/runs`.
- Публичные исходные Tardis gzip *не* копируются в репозиторий. Скрипт только экспортирует компактные аудиты источников.

## Права и запуск
- Работающий первичный workflow: `.github/workflows/09l-auto-v1-isolated-pilot.yml` в исследовательской ветке.
- Для ежедневного unattended-расписания GitHub требует workflow в `main`. Планировщик `.github/workflows/09l-auto-v1-daily.yml` минимально добавляется туда, но выполняет только код ветки `research/09l-auto-v1-20261022` и записывает **только** `research/09l/auto/v1/derived` в эту исследовательскую ветку. Никаких торговых сделок, Futures, NAV и другой канонической записи.
- До подключения CoinGlass и приватного хранилища автоматизируется только общедоступный исторический реестр, а не Model2 PIT. Приватные API-ключи НЕ присылать в чат и НЕ хранить в публичной ветке. Работа с секретами требует отдельной защищённой конфигурации и проверки лицензии API.

## Научные статусы
`SOURCE_AUDIT_OK` — криптоисточники за конкретную дату проверены. `DATA_INCOMPLETE` — нет полного источника. `PIT_SNAPSHOT_MISSING` — кластерный PIT не сохранён. `PIT_SNAPSHOT_STORED_PRIVATELY` — получена и сохранена настоящая предварительная карта, только тогда можно строить хронологическую историю.
Все существующие наблюдения 09L остаются **описательными**: нет калиброванной вероятности каскада или первого достижения кластера.
