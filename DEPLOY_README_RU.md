## Развёртывание

Содержимое каталога архива перенести в корень `analiticprosp-ship-it/crypto-price-feed` (с сохранением вложенных каталогов). `.github/workflows/update-prices.yml` заменяет существующий файл; остальные файлы новые. Существующие `universe.json`, `market-structure.json`, `prices.json` и `scripts/update_market_structure.py` не удалять. Сначала проверить права `Actions: Read and write`, разрешённые политикой репозитория. Затем вручную запустить в указанном порядке workflows: **Update critical crypto prices**, **Update independent research quotes**, **Daily tokenomics snapshot**, **Watch critical quote freshness**. Проверить generatedAt и валидность по тикерам, а не только зелёный статус workflow. Есть отдельный best-effort сторожевой workflow `watch-price-freshness.yml`: каждые 10 минут проверяет возраст `prices.json`, при возрасте >10 минут или ошибке чтения пытается запустить `update-prices.yml` через GitHub API. Ему необходимы `actions: write` и разрешённый `GITHUB_TOKEN`; он тоже зависит от расписания GitHub и не предоставляет 100% SLA. Возможны задержки расписания GitHub Actions; целевая периодичность не является SLA.

`prices.json` остаётся **единственным источником системной цены**: <=15 минут, каждый инструмент отдельно `ok=true` и положительный systemPrice. Исследовательский `research-prices.json`, структура рынка и `tokenomics.json` никогда не заменяют его. Основные 12 Spot и 5 Perpetual проверяются строго; дополнительные 3 P0 Spot и 4 Perpetual запрашиваются параллельно с изоляцией ошибок, сохраняют прежнее присутствие при доступности и не блокируют основные котировки. Исследовательские P1/P2 и расширенные Futures собираются отдельно с явным статусом Н/Д.

`tokenomics.json`: 15 ID CoinGecko (включая пыль). `circulatingSupply`, `totalSupply`, `maxSupply` — сопоставимый датированный снимок одного поставщика. `lockedSupply`, `netEmission`, полный `unlockWindows.totalExpectedTokens` и прогноз dilution остаются null, пока не получен подтверждённый источник именно этих метрик. Отсутствие записи о разблокировке **не равно нулю**. В `tokenomics-events.json` два различных документальных события ENA 05.10; их объёмы неизвестны и не суммируются. CoinGecko public `/coins/markets` может вернуть HTTP 429 — по желанию в GitHub Actions Secrets добавить `COINGECKO_DEMO_API_KEY`. Никакие рыночные цены из CoinGecko не использовать в NAV/P&L/«Сделка».

Проверка качества: перед запуском `python -m unittest discover -s tests -v`; `python -m py_compile scripts/*.py`. В GitHub проверить, что все 15 записей имеют точные ID, а HTTP-ошибки явно отображены в providerError и N/A (не подменены прошлым снимком).

Сопутствующие проектные редакции `01_MASTER_v1.15.15...md` и `02_RESEARCH_v1.7.6...md` описывают **целевую** архитектуру, не выдают развёртывание за состоявшийся факт. После подтверждённой публикации заменить закреплённые файлы проекта 01 и 02.
